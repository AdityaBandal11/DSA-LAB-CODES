# 📘 DSA Lab Codes

This repository contains **Data Structures & Algorithms (DSA) Laboratory Programs** implemented as part of the **SPPU (Savitribai Phule Pune University)** curriculum.
Each program focuses on understanding **core data structures, algorithm design, and implementation techniques** in C/C++.

---

## 🧠 Subject Details

- **Subject Name:** Data Structures & Algorithms (DSA) Lab  
- **Course:** Engineering (SPPU)  
- **Lab Work:** Practical implementation of DSA concepts  
- **Languages Used:** C, C++,python

---

## 📚 Topics Covered

This repository includes implementations for:

- **Arrays & Linked Lists**
- **Stacks & Queues**
- **Trees & Binary Search Trees**
- **Graphs**
- **Sorting Algorithms (Quick, Merge, Bubble, etc.)**
- **Searching Algorithms**
- **Hashing**
- **Recursion**
- **File Handling (where applicable)**
